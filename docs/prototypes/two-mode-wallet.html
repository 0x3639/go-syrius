Where I'd adjust the brief

You asked me to check the split rather than take it as given. Everyday stays small on purpose; these are the calls I made.

Operator tools are named in Everyday, not opened

More tools lists Pillars, Sentinels, token issuance, Accelerator-Z and node management under "Advanced mode only". Choosing one switches mode after saying so. Holders never see launch forms, but can find out they exist.

Delegating stays in Earn

Picking a pillar to delegate to is a holder action, so it sits with staking and rewards. Running a pillar is not, so registration, pillar stats and voting are Advanced.

Held tokens always show

Hiding token issuance must not hide tokens you hold. Home lists every asset, with "No price" where there is none.

Obligations cross the line

A pillar owner in Everyday still sees one line about a waiting vote, and a stalled node still warns that balances may be stale. Both lead into Advanced rather than rebuilding the tool.

Plasma is a tool, not a home tile

Holders only need to know if the next transaction is instant. Everyday shows that inside the review and puts fusion under More tools.

The incoming count never toggles anything

Today the top-bar icon carrying the count switches auto-receive. Here the count opens the payments, and auto-receive is a labelled switch on Receive and in Settings.
